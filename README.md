Este es un proyecto sobre un sitio web del Instituto Superior de comercio Francisco Araya Bennett que contiene información sobre cada laboratorio que se usa en la especialidad de programación, tanto como en otras especialidades que tambien los usan.

1. index.html (Inicio):
Es la página principal del sitio web. Presenta información general sobre el liceo, sus especialidades y accesos a las demás páginas mediante un menú de navegación.

2. quienes-somos.html (Quiénes somos):
Contiene información sobre el INSUCO Valparaíso, su comunidad educativa y los objetivos del establecimiento.

3. sobre-mi.html (Sobre mí):
Presenta información personal del estudiante que realizó el proyecto. Incluye una fotografía con un pequeño efecto de zoom al pasar el cursor.

4. contacto.html (Contacto):
Permite a los visitantes revisar los datos de contacto del establecimiento y completar un formulario para enviar consultas.

5. laboratorios/laboratorios.html (Laboratorios):
Muestra información sobre los cinco laboratorios de computación, incluyendo imágenes, descripciones y horarios de disponibilidad según los datos registrados.

6. css/style.css (Diseño del sitio):
Contiene los estilos que se aplican a las páginas, como los colores beige, los tamaños de texto, los menús, las imágenes y la distribución de los elementos. También permite que el sitio se adapte a celulares y computadores.

8. Carpeta img/ (Imágenes):
Esta carpeta guarda el logo del liceo en todas las paginas y las imágenes utilizadas para representar las distintas especialidades que salen en el index(inicio) del sitio web.

9. Carpeta laboratorios/imagenes/ (Imágenes de laboratorios):
Contiene las fotografías que se muestran en la página de laboratorios.

En resumen: Este sitio web del INSUCO Valparaíso busca organizar y presentar información del establecimiento en diferentes páginas. Cada archivo HTML cumple una función específica, mientras que el archivo CSS se encarga del diseño y las imágenes complementan el contenido. Además, el menú facilita la navegación y el diseño adaptable permite utilizar el sitio desde distintos dispositivos.
